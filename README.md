# Casino_system
___
## О проекте
___
Проект является сервисом для хранения и обработки информации о посетителях казино, а также сервисом пропускной системы.
## Возможности системы
___
В проекте реализованы данные возможности:
- регистрация пользователей;
- авторизация пользователей;
- управление пользователями;
- хранение данных пользователей;
- изменение данных пользователей;
- игра со ставкой;
- хранение данных о счёте пользователей;
- депозит;
- снятие денег со счета.

## Архитектура проекта
___
Система состоит из трех слоев классической архитектуры, где слой данных разделен на базу данных (БД) и систему управления базой данных (СУБД).

`Слой интерфейса -- Слой логики -- СУБД -- БД`

Архитектура позволяет разделять данные, алгоритмы взаимодействия с ними и взаимодействие системы с пользователем.

## Установка
___
### 1. Клонирование репозитория
```
git clone https://github.com/DanRus717/Casino_system.git
cd Casino_system
```
### 2. Создание виртуального окружения
```
python -m venv .venv
```
### 3. Активация виртуального окружения
Windows PowerShell:
```
.venv\Scripts\Activate.ps1
```
Windows Command Prompt:
```
.venv\Scripts\activate.bat
```
Linux и macOS:
```
source .venv/bin/activate
```
### 4.Установка зависимостей (не реализовано)
```
pip install -r requirements.txt
```
